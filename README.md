# תקציב שנתי

אפליקציה חינמית לתקציב שנתי אישי: הכנסות, הוצאות, חסכונות ושווי נקי, חודש אחרי חודש.

**פותחים כאן:** https://taktziv-shnati.github.io/

- **פרטיות:** כל הנתונים נשמרים רק במכשיר שלך. אין שרת, אין הרשמה, ושום דבר לא נשלח לשום מקום.
- **התקנה:** עובדת בטלפון (אייפון ואנדרואיד) ובמחשב, ואפשר להתקין אותה כאפליקציה. אחרי ההתקנה היא עובדת גם בלי אינטרנט.
- **טעינת קבצים:** אפשר לטעון קובץ אקסל או CSV מהבנק או מחברת האשראי. הקובץ נקרא בתוך הדפדפן ולא יוצא מהמכשיר.
- **גיבוי:** בעזרת קובץ, ובמחשב (כרום ואדג') גם גיבוי אוטומטי לקובץ שבוחרים.

כלי מעקב אישי, לא ייעוץ פיננסי. הקוד כאן פתוח. אין בו שום מידע אישי, ונתוני הדוגמה מומצאים.

קריאת קבצי אקסל: [SheetJS](https://sheetjs.com) (רישיון Apache 2.0, ב-`vendor/`).
